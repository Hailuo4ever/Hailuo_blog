# A - To Zero

> 关键词：暴力

## 思路

模拟一下题意，从最大的数开始暴力即可。如果来到了偶数，我们应该一次性做完全部偶数的操作，直到它变成 $0$ 或奇数。

## Code

```c++
// Problem: CF 2075 A
// Contest: Codeforces - Educational Codeforces Round 176 (Rated for Div. 2)
// URL: https://codeforces.com/contest/2075/problem/A
// Time: 2026-11-25 22:27:04
#include <bits/stdc++.h>
#include <cassert>
using namespace std;

#ifdef LOCAL
#include "Debug.hpp"
#else
#define debug(...) ((void) 0)
#endif

#define endl '\n'
#define all(x) (x).begin(), (x).end()
#define eb emplace_back

using ll = long long;
using ld = long double;
using ull = unsigned long long;
using pii = pair<int, int>;
using pdd = pair<double, double>;
using pll = pair<long long, long long>;
using i128 = __int128;

const int dx[] = {-1, 0, 1, 0, -1, 1, 1, -1};
const int dy[] = {0, 1, 0, -1, 1, 1, -1, -1};
const int inf = 0x3f3f3f3f;
const int N = 0;
const ll INF = 4e18;

mt19937 rnd(chrono::steady_clock::now().time_since_epoch().count());
int rand(int l, int r)
{
    return uniform_int_distribution<int>(l, r)(rnd);
}

void solve()
{
    int n, k;
    cin >> n >> k;

    int res = 0;
    while (n)
    {
        for (int i = min(k, n);; i--)
        {
            if ((i & 1) == (n & 1))
            {
                if (i % 2 == 0)
                    res += n / i, n -= n / i * i;
                else
                    res++, n -= i;

                break;
            }
        }
    }

    cout << res << endl;
}

int main()
{
    ios::sync_with_stdio(0), cin.tie(0);

    int T = 1;
    cin >> T;

    while (T--)
        solve();

    return 0;
}
```

# B - Array Recoloring

> 关键词：分类讨论

## 思路

首先发现，如果 $k \ge 2$，说明我们实际上可以控制染色结束的那个点，此时答案为数组前 $k+1$ 大的数。

当 $k=1$ 时，分为从中间染和两边染两种情况，分类讨论即可。

```c++
{

    {
        ll mx = max(a[1], a[n]), res = a[1] + a[n];
        for (int i = 2; i <= n - 1; i++)
            res = max(res, a[i] + mx);

        return;
    }

    sort(a.begin() + 1, a.end(), greater<int>());

    ll res = 0;
    for (int i = 1; i <= k + 1; i++)
        res += (ll) a[i];

    cout << res << endl;

    ios::sync_with_stdio(0), cin.tie(0);
```

# C - Two Colors

> 关键词：二分

## 思路

> [!NOTE]
>
> 实现上注意不要搞乱 $n$ 和 $m$。

为了规避边界问题，我们可以在输入时将 $a[i]$ 和 $n-1$ 取最小，因为必须要有两种颜色且连续，所以一种颜色的上界是 $n-1$。

我们可以枚举每种颜色作为靠前的那个颜色来进行二分。为了避免重复选择或者选到自己，我们指定二分的边界为 $(i, m]$ 即可。

考虑如何计算答案，对于两种确定的颜色 $u,v$，他们对答案的贡献是 $a[u]+a[v]-n+1$。使用后缀和直接计算 $\sum a[v]$ 即可。

## Code

```c++
// Contest: Codeforces - Educational Codeforces Round 176 (Rated for Div. 2)
// URL: https://codeforces.com/contest/2075/problem/C

#include <cassert>
using namespace std;

#ifdef LOCAL
#include "Debug.hpp"
#else
#define debug(...) ((void) 0)
#endif

#define endl '\n'
#define all(x) (x).begin(), (x).end()
#define eb emplace_back

using ll = long long;
using ld = long double;
using ull = unsigned long long;
using pii = pair<int, int>;
using pdd = pair<double, double>;
using pll = pair<long long, long long>;
using i128 = __int128;

const int dx[] = {-1, 0, 1, 0, -1, 1, 1, -1};
const int dy[] = {0, 1, 0, -1, 1, 1, -1, -1};
const int inf = 0x3f3f3f3f;
const int N = 2e5 + 10;
const ll INF = 4e18;

mt19937 rnd(chrono::steady_clock::now().time_since_epoch().count());
int rand(int l, int r)
{
    return uniform_int_distribution<int>(l, r)(rnd);
}

{
    ll n, m;
    cin >> n >> m;

    vector<ll> a(m + 1);
    for (int i = 1; i <= m; i++)
        cin >> a[i], a[i] = min(a[i], n - 1);

    sort(a.begin() + 1, a.end());
    vector<ll> suf(m + 2);

    for (int i = m; i >= 1; i--)
        suf[i] = suf[i + 1] + a[i];

    ll res = 0;
    for (int i = 1; i <= m; i++)
    {
        auto it = lower_bound(a.begin() + i + 1, a.end(), n - a[i]);
        if (it == a.end())
            continue;

        ll pos = it - a.begin(), cnt = m - pos + 1;
        debug(cnt);
        res += cnt * (a[i] - n + 1) + suf[pos];
    }

    cout << res * 2 << endl;
}

int main()
{
    ios::sync_with_stdio(0), cin.tie(0);

    int T = 1;
    cin >> T;

    while (T--)
        solve();

    return 0;
}
```

# D - Equalization

> 关键词：预处理，背包DP

## 思路

首先我们注意到，除以 \(2^k\) 并向下取整，本质上就是二进制右移 \(k\) 位。因此，我们根本不需要关心操作顺序，只需要关心 $x$ 一共右移的位数 $i$ 和 $y$ 一共右移的位数 $j$。最终只需要满足 $(x\gg i)=(y\gg j)$。

不难发现，$i,j$ 的范围非常小，并且还有一个性质：$dp[i][j]$ 的值与 $(x,y)$ 的具体数值没有任何关系。这引导我们直接预处理出所有可能代价。

考虑枚举每一个 $k$，容易将原问题转化成一个 $01$ 背包问题。

设 $f[k][i][j]$ 表示只考虑编号为 $1,2,\ldots,k$，使得 $x$ 右移 $i$ 位，$y$ 右移 $j$ 位的最小代价。

考虑第 $k$ 个操作，有三种情况：

1. 不用，$f[k][i][j]\gets f[k-1][i][j]$；
2. 分配给 $x$：$f[k][i][j]\gets f[k-1][i-k][j]+2^k$；
3. 分配给 $y$：$f[k][i][j]\gets f[k-1][i][j-k]+2^k$。

初始化为 $f[0][0][0]=0$。同样可以通过倒序枚举优化掉第一维空间。

## Code

```c++
// Problem: CF 2075 D
// Contest: Codeforces - Educational Codeforces Round 176 (Rated for Div. 2)
// URL: https://codeforces.com/contest/2075/problem/D
// Time: 2026-11-25 22:27:05
#include <bits/stdc++.h>
#include <cassert>
using namespace std;

#ifdef LOCAL
#include "Debug.hpp"
#else
#define debug(...) ((void) 0)
#endif

#define endl '\n'
#define all(x) (x).begin(), (x).end()
#define eb emplace_back

using ll = long long;
using ld = long double;
using ull = unsigned long long;
using pii = pair<int, int>;
using pdd = pair<double, double>;
using pll = pair<long long, long long>;
using i128 = __int128;

const int dx[] = {-1, 0, 1, 0, -1, 1, 1, -1};
const int dy[] = {0, 1, 0, -1, 1, 1, -1, -1};
const int inf = 0x3f3f3f3f;
const int N = 60;
const ll INF = 4e18;

mt19937 rnd(chrono::steady_clock::now().time_since_epoch().count());
int rand(int l, int r)
{
    return uniform_int_distribution<int>(l, r)(rnd);
}

vector<vector<ll>> dp(N, vector<ll>(N, INF));

void init()
{
    dp[0][0] = 0;
    for (int k = 1; k <= 16; k++)
    {
        for (int i = N - 1; i >= 0; i--)
            for (int j = N - 1; j >= 0; j--)
            {
                if (dp[i][j] == INF)
                    continue;

                int u = min(N - 1, i + k), v = min(N - 1, j + k);
                dp[u][j] = min(dp[u][j], dp[i][j] + (1ll << k));
                dp[i][v] = min(dp[i][v], dp[i][j] + (1ll << k));
            }
    }
}

void solve()
{
    ll x, y;
    cin >> x >> y;

    ll ans = INF;

    for (int i = 0; i < N; i++)
        for (int j = 0; j < N; j++)
            if ((x >> i) == (y >> j))
                ans = min(ans, dp[i][j]);

    cout << ans << endl;
}

int main()
{
    ios::sync_with_stdio(0), cin.tie(0);

    int T = 1;
    cin >> T;

    init();

    while (T--)
        solve();

    return 0;
}

```
