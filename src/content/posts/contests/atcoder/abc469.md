# C - Cantrip

> 关键词：思维

## 思路

假设前 $k$ 个袋子中装有 $h$ 个 $o$，$k-h$ 个 $x$，他会一直往后拿。注意到如果他继续拿到 $o$ 袋子，操作次数不变，否则操作次数 $-1$。因此他会往后一直拿到 $h$ 个 $x$ 袋子后停下。而由于前面有 $k-h$ 个 $x$，所以他停下的位置就是字符串里第 $k-h+h=k$ 个 $x$ 的位置。

如果字符串中不存在第 $k$ 个 $x$，说明他可以直接拿到最后，答案为 $n$。

```c++
    }
}
```

# D - The Big Two

> 关键词：图论建模

## 思路

把每位玩家看作一个顶点，第 $m$ 场比赛的两位决赛选手 $A_m,B_m$ 之间连一条边。现在要选择两个玩家 $x,y$，要求每场比赛中至少有一个人是 $x$ 或 $y$。也就是**选择两个顶点 $x,y$，使得图中的每条边都至少有一个端点是 $x$ 或 $y$。**

考虑第一场比赛 $(A_1,B_1)$，为了覆盖这条边，合法的 $(x,y)$ 必须满足两个里面至少有一个等于 $A_1$ 或 $B_1$。所以我们分别计算包含 $A_1$ 的合法二元组数量和包含 $B_1$ 的合法二元组数量即可。

假设我们已经确定选择玩家 $p$，接下来要统计有多少个玩家 $q$，使得 $\{p,q\}$ 可以覆盖所有边。所有与 $p$ 相连的边已经被 $p$ 覆盖，不需要考虑，只需要看那些两个端点都不是 $p$ 的边。$q$ 必须同时出现在这些边中。

找到第一条不与 $p$ 相连的边 $(u,v)$，因为这条边没有被 $p$ 覆盖，所以必须由 $q$ 覆盖。必然有 $q=u\quad\text{或}\quad q=v$。对于这两个候选的 $q$，再遍历所有边，检查每条边是否至少连接 $p$ 或 $q$。

假如所有边都与 $p$ 相连，答案为 $n-1$。

假如 $\{A_1,B_1\}$ 也是合法的二元组，它会被重复计算，因此最后需要减掉一次。

## Code

```c++
// Problem: AT ABC469 D
// Contest: AtCoder - AtCoder Beginner Contest 469
// URL: https://atcoder.jp/contests/abc469/tasks/abc469_d
// Time: 2026-08-01 20:12:04
#include <bits/stdc++.h>
using namespace std;

// clang-format off
#define endl '\n'
#define all(x) (x).begin(), (x).end()
#define fastio() ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
#define eb emplace_back
// clang-format on

using ll = long long;
using ld = long double;
using ull = unsigned long long;
using pii = pair<int, int>;
using pdd = pair<double, double>;
using pll = pair<long long, long long>;
using i128 = __int128;

const int dx[] = {-1, 0, 1, 0, -1, 1, 1, -1};
const int dy[] = {0, 1, 0, -1, 1, 1, -1, -1};
const int inf = 0x3f3f3f3f;
const int N = 2e5 + 10;
const ll INF = 4e18;
const ll mod = 1;

struct Edge
{
    int u, v;
} edges[N];

void solve()
{
    int n, m;
    cin >> n >> m;

    for (int i = 1; i <= m; i++)
    {
        int u, v;
        cin >> u >> v;
        edges[i] = {u, v};
    }

    auto check2 = [&](int u, int a) -> bool
    {
        // cerr << "qwq" << endl;
        for (int i = 1; i <= m; i++)
        {
            auto [p, q] = edges[i];
            if ((p != u && p != a) && (q != u && q != a))
                return false;
        }
        return true;
    };

    auto check = [&](int u) -> int
    {
        int a = -1, b = -1;
        for (int i = 1; i <= m; i++)
        {
            auto [p, q] = edges[i];
            if (u != p && u != q)
            {
                a = p, b = q;
                break;
            }
        }

        if (a == -1 && b == -1)
            return n - 1;

        // cerr << "qwq" << endl;

        int res = 0;
        if (check2(u, a))
            res++;

        if (check2(u, b))
            res++;

        return res;
    };

    int u = edges[1].u, v = edges[1].v;

    int res = check(u) + check(v);

    if (check2(u, v))
        res--;

    cout << res << endl;
}

int main()
{
    fastio();

    int T = 1;
    // cin >> T;

    while (T--)
        solve();

    return 0;
}
```
