# B - Corridor Watch

> 关键词：模拟

## 思路

由于数据范围比较小，可以对每个 $G$ 格子向两边拓展来模拟。划定左边界为 `l = max(0, i - d)`，右边界 `r = min(m - 1, i + d)`。

# D - Pre-Palindrome

> 关键词：枚举

## 思路

由于每个连续子串都有唯一的中心，我们可以枚举中心点，并向外扩展左边界和右边界。比较关于中心对称的字符 $s_l$ 和 $s_r$。

设不相等的对称字符对数量为 $cnt$。

- $cnt=0$：本身就是回文串；
- $cnt=1$：修改这一对中的任意一个字符，就能变成回文串；
- $cnt\ge 2$：至少需要修改两个字符，此时当前子串和后续子串都无法满足条件。

对于奇数长度和偶数长度的子串分开枚举，偶数的中心点有两个，奇数有一个。

## Code

```c++

#define endl '\n'

#define eb emplace_back
// clang-format on

using ll = long long;
using ull = unsigned long long;
using pii = pair<int, int>;
using pdd = pair<double, double>;
using pll = pair<long long, long long>;
using i128 = __int128;

const int dx[] = {-1, 0, 1, 0, -1, 1, 1, -1};
const int dy[] = {0, 1, 0, -1, 1, 1, -1, -1};
const int inf = 0x3f3f3f3f;
const ll INF = 4e18;
const int N = 0;

void solve()
{
    string s;
    cin >> s;

    int n = s.size();

    ll res = 0;

    // len = odd
    for (int mid = 0; mid < n; mid++)
    {
        int cnt = 0;
        for (int l = mid, r = mid; l >= 0 && r < n; l--, r++)
        {
            if (s[l] != s[r])
                cnt++;

                res++;
            else

        }

    for (int mid = 0; mid + 1 < n; mid++)
    {
        int cnt = 0;
        for (int l = mid, r = mid + 1; l >= 0 && r < n; l--, r++)
        {
            if (s[l] != s[r])
                cnt++;

            if (cnt <= 1)
                res++;
            else
                break;
        }
    }

    cout << res << endl;
}
```

# E - Sum of Average

> 关键词：推公式

## 思路

要求计算所有子数组的**算术平均值之和**：$\sum_{1\le l\le r\le N}
\frac{A_l+A_{l+1}+\cdots+A_r}{r-l+1}
\pmod {998244353}$

不能枚举 $O(n^2)$ 个子数组，考虑计算每个 $A_i$ 对答案的贡献。设答案为 $A_1C_1+A_2C_2 \ldots A_nC_n$，考虑如何计算系数。

从 $A_1$ 入手，$A_1$ 出现在所有左端点为 $1$ 的子数组 $[1,1],[1,2],\ldots,[1,n]$，它们的长度分别是 $1,2,\ldots,n$，所以 $C_1=1+\frac12+\frac13+\cdots+\frac1n$。

考虑 $A_2$，包含它的数组满足 $l\le 2\le r$，左端点只有 $l=1,l=2$ 两种可能。$l=2$ 时，子数组 $[2,2],[2,3],\ldots,[2,n]$，长度分别为 $1,2,\ldots,n-1$，贡献为 $1+\frac12+\cdots+\frac1{n-1}$。当 $l=1$ 时，子数组 $[1,2],[1,3],\ldots,[1,n]$，长度分别为 $2,3,\ldots,n$，贡献为 $\frac12+\frac13+\cdots+\frac1n$。所以 $C_2=
\left(1+\frac12+\cdots+\frac1{n-1}\right)
+
\left(\frac12+\frac13+\cdots+\frac1n\right)$。

考虑 $A_3$，$l=3$ 的贡献为 $C_1=1+\frac12+\frac13+\cdots+\frac1{n-2}$，$l=2$ 的贡献为 $\frac12+\frac13+\frac14+\cdots+\frac1{n-1}$，$l=1$ 的贡献为 $\frac13+\frac14+\frac15+\cdots+\frac1{n}$。因此 ${
C_3=
\left(1+\frac12+\cdots+\frac1{n-2}\right)
+
\left(\frac12+\frac13+\cdots+\frac1{n-1}\right)
+
\left(\frac13+\frac14+\cdots+\frac1n\right)
}$

这里就看出规律了，处理逆元的前缀和，递推系数算答案即可。

## Code

```c++
// Problem: AT ABC468 E
// Contest: AtCoder - AtCoder Beginner Contest 468
// URL: https://atcoder.jp/contests/abc468/tasks/abc468_e
// Time: 2026-07-25 20:24:22
#include <bits/stdc++.h>
using namespace std;

// clang-format off
#define endl '\n'
#define all(x) (x).begin(), (x).end()
#define fastio() ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
#define eb emplace_back
// clang-format on

using ll = long long;
using ull = unsigned long long;
using pii = pair<int, int>;
using pdd = pair<double, double>;
using pll = pair<long long, long long>;
using i128 = __int128;

const int dx[] = {-1, 0, 1, 0, -1, 1, 1, -1};
const int dy[] = {0, 1, 0, -1, 1, 1, -1, -1};
const int inf = 0x3f3f3f3f;
const ll INF = 4e18;
const int N = 0;
const ll mod = 998244353;

ll qmi(ll a, ll x)
{
    ll res = 1;
    a = a % mod;

    while (x)
    {
        if (x & 1)
            res = (res * a) % mod;
        a = (a * a) % mod;
        x >>= 1;
    }
    return res % mod;
}

ll get_inv(ll x)
{
    return qmi(x, mod - 2) % mod;
}

void solve()
{
    int n;
    cin >> n;

    vector<ll> a(n + 1), inv(n + 1), pre(n + 1);

    for (int i = 1; i <= n; i++)
        cin >> a[i];

    for (int i = 1; i <= n; i++)
    {
        inv[i] = get_inv(i);
        pre[i] = (pre[i - 1] + inv[i]) % mod;
    }

    ll res = 0;

    ll c = pre[n];
    for (int i = 1; i <= n; i++)
    {
        res = (res + (a[i] * c) % mod) % mod;
        c = (c + pre[n - i] - pre[i] + mod) % mod;
    }

    cout << res << endl;
}

int main()
{
    fastio();

    int T = 1;
    // cin >> T;

    while (T--)
        solve();

    return 0;
}

```

# F - Chmax

> 关键词：DP，分类讨论

## 思路

首先考虑模拟一下操作。不妨设每次操作时 $x\le y$，即较小的数是 $x$，较大的数是 $y$。

设当前处理到元素 $p$，我们考虑当 $p>y$ 时，无论将 $p$ 放到哪里都能得一分，但显然放到 $y$ 上更好，因为保留了一个更小的变量 $x$，以后更容易让后面的元素超过它。因此在最优方案中，当 $p>y$ 时，一定可以选择 $y\leftarrow p$ 并保留 $x$。

这意味着，$y$ 会依次记录所有出现过的前缀最大值。例如 $4,3,6,2,8,5$，前缀最大值依次是 $4,6,8$，这些元素一定可以被放进 $y$，且每个都会产生 $1$ 分的贡献。

如果 $p$ 不是前缀最大值，当前必然有 $p<y$。此时有两种处理方式，一种是放进较大的变量 $y$，这样操作不会改变 $y$ 的值且不贡献分数，因此相当于忽略了当前的 $p$；另一种是放进较小的变量 $x$，如果 $p>x$ 则得到一分，并赋值给 $x$。如果 $p<x$ 则无法得分。因此，非前缀最大值想要贡献分数，必须依次满足 $p_1<p_2<p_3<\cdots$。也就是说，**所有放入 $x$ 并成功得分的非前缀最大值，必须构成一个严格递增子序列。**

因此答案为前缀最大值的数量加上非前缀最大值序列的最长上升子序列长度。

使用一个 $f$ 数组维护最长上升子序列。定义 $f[k-1]$ 表示目前所有长度为 $k$ 的递增子序列中，最小的结尾值。对于每个数 $x$，如果找不到 $\ge x$ 的位置，说明可以接在后面；否则用 $x$ 替换该位置，这样做的目的是保证结尾尽可能地小，以便后续扩展。**注意 $f$ 数组并不表示最长子序列，它只维护长度**。这里是解决 $LIS$ 问题的另一种做法。

> [!NOTE]
>
> 注：$LIS$ 的这种解法的代码：[记录详情 - 洛谷 | B3637 - 最长上升子序列](https://www.luogu.com.cn/record/288601747)
