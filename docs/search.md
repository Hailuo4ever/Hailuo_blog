# 文章搜索

导航栏快捷搜索与 `/search/` 共用 Pagefind 搜索服务。索引在生产构建末尾生成，只包含 `posts/**/*.html`，统一使用中文分词；文章公开元信息与正文可检索，加密容器、公式渲染及其他标记为忽略的内容不参与索引。

## 使用方式

- `Ctrl/Cmd + K` 聚焦搜索，上下键选择，Enter 打开结果，Esc 关闭并恢复焦点。
- 快捷搜索只读取前 5 条详情；完整搜索页每页读取 10 条详情。
- 分类单选、标签多选，多个标签要求同时满足；无关键词时可按筛选浏览文章，默认最新发布优先。
- 支持相关度、最新发布、最早发布排序。
- 默认全部关键词命中；无结果时可手动切换为任一关键词匹配。引号内短语不会被拆成多个放宽条件。
- 英文完整词及引号短语通过精确检索结果 ID 的交集校验，避免 Pagefind 把不存在的长词缩短为代码变量；保留候选结果的相关度排序。

URL 参数：`q`、`category`、可重复的 `tag`、`sort=newest|oldest`、`page`、`match=any`。默认值省略，筛选和关键词变更重置页码。浏览器前进／后退由搜索组件恢复，跨页面跳转继续使用 Swup。

初始化失败不会伪装成空结果。重试会重新初始化，并使用新的模块 URL 绕过浏览器对失败导入的缓存。两个入口分别管理防抖与请求序号，过期请求无法回写界面。

## 验证

```sh
pnpm test:search
pnpm type-check
pnpm check
pnpm build
pnpm exec astro preview
```

开发服务器不提供模拟搜索结果，显示构建预览提示。真实检索与网络性能须在构建预览中验证。

回归场景：

- `动态规划`：标题命中的笔记位于前列；`ICPC` 与 `icpc` 返回相同结果。
- `zzzxxyyunknown`：不应命中代码变量 `z`。
- `线段树 zzzxxyyunknown`：严格搜索为空，手动放宽后可找到线段树相关文章。
- `Algorithm`：验证分页、日期排序；`算法笔记` 与 `Notebook` 标签同时筛选，结果必须都含有两个标签。
- 刷新、分享 URL、前进后退、从结果文章返回，状态保持一致。
- 阻断 `/pagefind/pagefind.js` 后解除阻断，点击重试可以恢复；慢网下连续输入、清空或关闭不会出现旧结果。
- 新浏览器上下文中，快捷搜索最多请求 5 个详情片段，搜索页首屏最多请求 10 个。
- 检查桌面／移动端、明暗主题、中文输入法和键盘操作；新增草稿或加密文章时确认其私有正文未进入索引。
